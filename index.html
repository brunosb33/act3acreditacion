Pensar paso a paso

Un algoritmo es una receta precisa para resolver un problema. En estas 7 actividades vas a reconocerlos, completarlos, ordenarlos y crearlos. Empiezan fáciles y se ponen más desafiantes.

Importante: la tarea vale 10 puntos. Cada actividad se envía una sola vez. Podés cambiar tus respuestas todas las veces que quieras hasta enviarla, y cada error descuenta puntos.

01

Concepto

¿Es un algoritmo?

Para ser un algoritmo, las instrucciones tienen que ser precisas (sin ambigüedad), estar ordenadas y ser finitas (terminar en algún momento).

El algoritmo del mate

Arrastrá los pasos (o usá las flechas) hasta dejarlos en un orden que funcione. Pista: a veces hay más de un orden correcto, lo importante es que cada paso tenga listo lo que necesita.

    04

    Completar pseudocódigo

    ¿Par o impar?

    MOD da el resto de una división. Si numero MOD 2 es 0, el número es par. Una condición (Si… Entonces… SiNo) elige qué camino seguir.

    Tocá una palabra del banco y después tocá el hueco donde va. Tocá un hueco lleno para vaciarlo.

      Ordenar código

      Sumar del 1 hasta N

      Un ciclo (Mientras… Hacer) repite instrucciones mientras una condición sea verdadera. Este algoritmo debe leer n y mostrar 1 + 2 + … + n. Ordená las líneas para que funcione.
